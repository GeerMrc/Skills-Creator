## 一、审核目标

### 1.1 主要目标

1. **验证项目健康度** - 从架构、代码质量、文档一致性等多维度评估
2. **识别改进机会** - 发现潜在问题和优化空间
3. **确保规范符合度** - 验证是否遵循 CLAUDE.md 定义的开发规范
4. **提供可执行建议** - 生成具体的改进计划和优先级排序

### 1.2 审核原则

- **100% 基于实际代码** - 不依赖文档记录或 git commit 摘要
- **结构化评分** - 每个维度都有明确的评分标准
- **可操作改进** - 所有发现都有具体的改进建议
- **遵循开发规范** - 严格按照 CLAUDE.md 七步法执行
