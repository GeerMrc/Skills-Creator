## 十、开发规范概述

### 九步法流程

```
步骤0: 前置任务审核  → 检查前置任务、确认Git环境
步骤1: 制定开发计划  → 本文件
步骤2: 拆分任务清单  → 本章节八个任务
步骤3: 执行开发工作  → 逐个修复
步骤4: 测试验证      → pytest --cov
步骤5: 交叉验证      → 对照本文件检查
步骤6: 更新文档      → CHANGELOG.md
步骤7: 阶段性审计    → 本文件验证
步骤8: Git提交       → feat(fix): ...
步骤9: 阶段性汇报    → 归档本文件
```

### Git规范

**分支策略**:
```
main (生产)
  └─ develop (开发)
      └─ feature/* (功能)
```

**Commit格式**:
```
<type>(<scope>): <subject>

类型: feat/fix/docs/refactor/test/chore
示例: fix(test): 修复导入错误
```
