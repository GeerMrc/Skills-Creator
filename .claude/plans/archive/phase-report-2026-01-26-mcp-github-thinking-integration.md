- 团队协作原生化

**价值**:

- PR描述自动生成（含验证和分析结果）

**功能**:
- 验证失败自动创建Issue
- 分析过程完整思考记录
- 思考会话可导出为文档

**价值**:
- 问题遗漏率0%
- 决策完全可追溯
- 知识传递高效
