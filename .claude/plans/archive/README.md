## 命名规范

计划文档命名格式：`{类型}-{描述}-{日期}.md`

| 类型 | 前缀 | 说明 |
|------|------|------|
| 主计划 | `main-` | 项目总体开发计划 |
| 功能计划 | `feat-` | 新功能开发计划 |
| 修复计划 | `fix-` | Bug修复计划 |
| 审计报告 | `audit-` | 项目审计报告 |
| 文档计划 | `docs-` | 文档相关计划 |
| 发布计划 | `release-` | 发布准备计划 |

## 归档标准

符合以下任一条件的计划将被移至本目录：

1. **已完成**: 计划中的所有任务已完成
2. **已过期**: 计划内容已被新计划替代
3. **历史记录**: 需要保留作为历史参考
