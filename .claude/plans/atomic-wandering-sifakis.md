## 三、规范的开发流程概述

### 3.1 开发流程七步法

```
┌─────────────────────────────────────────────────────────────────┐
│                        完整开发流程                              │
├─────────────────────────────────────────────────────────────────┤
│  步骤1: 制定开发计划 → 步骤2: 拆分任务清单 → 步骤3: 执行开发工作  │
│       ↓                                                          │
│  步骤4: 测试验证 → 步骤5: 交叉验证 → 步骤6: 更新文档 → 步骤7: 审计 │
└─────────────────────────────────────────────────────────────────┘
```

### 步骤1: 制定开发计划
- 在 `.claude/plans/` 创建或选择计划文档
- 明确目标、范围、交付物
- 定义验收标准

### 步骤2: 拆分任务清单
- 使用 TodoWrite 工具创建任务清单
- 标注优先级 (P0/P1/P2/P3)
- 识别依赖关系

### 步骤3: 执行开发工作
- 按优先级执行
- 保持提交原子性
- 持续测试

### 步骤4: 测试验证
- 编写或更新测试用例
- 运行完整测试套件
- 确保覆盖率不降低

### 步骤5: 交叉验证
- 对照计划检查完成度
- 验证验收标准
- 代码自审

### 步骤6: 更新文档
- 更新技术文档
- 更新CHANGELOG.md
- 检查交叉引用

### 步骤7: 阶段性审计
- 审查执行情况
